# Logo sources

Every logo here is self-hosted (no third-party request at runtime). Each file came from the owner's own brand page, press kit, website or official repository on Nov 6 2026. Where a file is "cropped", the only change is the SVG viewBox (or a raster crop) around the symbol of the official lockup, with the wordmark removed; colours and shapes are untouched. The logos belong to their owners, are used only to name the asset, chain or protocol on screen, and imply no endorsement.
