# Chainlink pricing on Arc

Noren reads Chainlink Data Feed proxy contracts on **Arc mainnet (chain ID 5042)** through read-only RPC calls (`eth_call`). Its payments continue to settle on the **Arc testnet local fork (chain ID 5042002)**. The listed feeds are live on Arc mainnet and are not available on Arc testnet. The pricing RPC never receives a key and Noren never sends a mainnet transaction. Set `NOREN_PRICE_RPC` or the server's `priceRpcUrl` option to change the read-only Arc mainnet RPC; the default is `https://arc-rpc.publicnode.com`.

Supported invoice currencies are USD, EUR, GBP, JPY, CAD, AUD, MXN, BRL and KRW. Each non-USD currency uses its fiat/USD proxy; every quote also reads the USDC/USD proxy. USD uses an exact synthetic USD/USD rate of 1. The proxy addresses live in `packages/core/src/pricing.ts`. The two proxies' `decimals()` and `latestRoundData()` are read live for every quote. The `NorenQuoter` contract is an unaudited on-chain reference consumer; the server uses the equivalent TypeScript calculation.

For an amount `A` in fiat minor units, fiat minor-unit decimals `m`, fiat/USD answer `F` with feed decimals `f`, and USDC/USD answer `U` with feed decimals `u`, Noren calculates:

```text
USDC base units = ceil(A × F × 10^6 × 10^u / (U × 10^(m+f)))
```

JPY and KRW use `m = 0`; the other supported currencies use `m = 2`. USDC has six base-unit decimals. Integer arithmetic and upward rounding avoid undercharging. Both answers must be positive, both `updatedAt` values must be nonzero, and neither round may be older than 90,000 seconds (the 86,400-second heartbeat plus one hour). A stale or unavailable feed rejects the quote; the API returns HTTP 503. `answeredInRound` is not used.

Each quote records both proxy addresses, answers, decimals, round IDs and update timestamps. Anyone can audit it later by calling `getRoundData(roundId)` on each proxy on Arc mainnet and repeating the formula. The invoice stores the quote and its USDC amount through invoice expiry. The customer proof binds that exact USDC amount, so later feed updates cannot change the invoice's settlement amount.

The pricing Vitest tests and the NorenQuoter Foundry tests require Arc mainnet RPC access; they fail when it is unavailable. The Foundry fork tests deploy the quoter only inside the local fork. The existing checkout Foundry tests use a separate Arc testnet local-fork fixture generated by `pnpm e2e`.

This consumer is unaudited. Review feed availability, heartbeat, and deployment addresses before using it for production pricing.
